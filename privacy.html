바탕달력 개인정보처리방침

시행일: 2026년 10월 22일

1. 다루는 정보

바탕달력은 사용자가 직접 입력한 일정 정보(제목, 날짜·시간, 반복, 메모, 캘린더 이름·색)만 다룹니다. 이름, 연락처, 위치, 기기 식별 정보 등은 수집하지 않습니다.

2. 구글 사용자 데이터 이용

  • 앱은 Google Drive API의 https://www.googleapis.com/auth/drive.file 권한만 사용합니다.
  • 이 권한으로 사용자의 구글 드라이브에 바탕달력_공유 폴더와 바탕달력_공유데이터.json 파일을 만들고, 그 파일만 읽고 씁니다. 드라이브의 다른 파일은 볼 수 없습니다.
  • 이 파일은 사용자 본인의 PC·휴대폰·태블릿(웹앱) 사이에서 일정을 맞추는 데에만 쓰입니다.

3. 저장 위치

일정은 사용자의 휴대폰·PC 안, 태블릿 웹앱(/cal/)의 경우 그 기기 브라우저 저장소 안, 그리고 사용자 본인의 구글 드라이브에만 저장됩니다. 웹앱의 구글 로그인 정보(접근 토큰)도 그 기기 브라우저에만 보관되며 약 1시간 뒤 만료됩니다. 개발자는 별도의 서버를 운영하지 않으며, 일정 정보를 받거나 볼 수 없습니다.

4. 제3자 제공

일정 정보를 누구에게도 제공하거나 판매하지 않습니다. 광고·분석 도구를 쓰지 않습니다.

5. 보관과 삭제

사용자는 언제든지 앱의 [공유 끄기]로 연결을 끊고, 구글 드라이브에서 바탕달력_공유 폴더를 지워 모든 공유 데이터를 삭제할 수 있습니다. 구글 계정 설정의 타사 연결에서 앱 접근 권한을 해제할 수도 있습니다.

6. Google API 서비스 사용자 데이터 정책 준수

바탕달력이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.
