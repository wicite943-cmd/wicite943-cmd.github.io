[구글 로그인으로 연결]을 누르면 휴대폰 앱·PC와 같은 바탕달력_공유데이터.json(구글 드라이브 바탕달력_공유 폴더)으로 일정을 맞춰요. 권한은 이 앱이 만든 파일만 볼 수 있는 최소 권한이에요. 로그인은 한 시간쯤 지나면 다시 확인하는데, 보통 저절로 넘어가요. 머리줄의 ☁ 가 깜빡이면 눌러서 다시 로그인하세요.

휴대폰 바탕달력 앱은 설정 → [공유 파일 직접 고르기]에서 이 폴더의 바탕달력_공유데이터.json을 고르면 함께 맞춰져요. 구글 드라이브의 내 드라이브 안에 '바탕달력' 같은 폴더를 하나 만들고 고르세요. 다른 컴퓨터에서도 같은 폴더를 고르면 일정이 합쳐지고, 이후로는 한쪽에서 고치면 몇 초 안에 다른 쪽에도 반영돼요. (창 위치·투명도 같은 설정은 컴퓨터마다 따로)
